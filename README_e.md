# 电赛智能小车

本项目面向全国大学生电子设计竞赛（电赛）智能小车类赛题，记录小车从硬件搭建、底层驱动到运动控制与整车调试的完整开发过程。

## 项目目标

- 实现小车稳定启动、停止、前进、后退与转向
- 完成直线行驶、定距行驶和定角度转向
- 支持编码器测速与闭环速度控制
- 根据赛题需求扩展循迹、避障、测距、视觉识别等功能
- 提高系统的实时性、稳定性和现场调试效率

## 主要功能

- 电机 PWM 调速
- 编码器速度与里程采集
- PID 速度环 / 位置环控制
- 差速转向控制
- 姿态与方向角检测
- OLED 状态显示
- 串口数据输出与参数调试
- 传感器数据采集与任务逻辑控制

## 硬件组成

| 模块 | 说明 |
| --- | --- |
| 主控 | STM32 系列单片机（根据实际型号修改） |
| 电机 | 直流减速电机 |
| 电机驱动 | TB6612 / L298N / 其他驱动模块 |
| 测速模块 | 增量式编码器 |
| 姿态传感器 | MPU6050 / 陀螺仪模块 |
| 巡线模块 | 灰度传感器或摄像头 |

| 调试模块 | OLED、串口、按键与蜂鸣器 |
| 电源 | 锂电池与稳压模块 |

## 软件设计

项目程序建议按功能划分为以下模块：

```text
├─ Core          # 主程序、定时器与中断
├─ Drivers       # 电机、编码器、OLED、传感器驱动
├─ Control       # PID、速度控制、转向控制
├─ Algorithm     # 循迹、定位、路径规划等算法
├─ App           # 任务状态机与赛题流程
└─ README.md     # 项目说明
```

## 控制流程

1. 初始化主控、定时器、PWM、编码器和传感器。
2. 周期性采集编码器、姿态及环境信息。
3. 根据目标速度和运动任务计算控制量。
4. 通过 PID 调节左右电机 PWM 占空比。
5. 判断任务完成条件并切换小车运行状态。

## 快速开始

1. 按照实际接线检查电源、电机驱动和传感器接口。
2. 使用 Keil、STM32CubeIDE 或对应开发环境打开工程。
3. 根据硬件修改引脚、定时器和传感器参数。
4. 编译程序并下载到主控板。
5. 将小车架空测试电机方向和编码器反馈。
6. 低速落地测试，逐步整定 PID 参数。

## 调试建议

- 首次上电前检查电源极性，避免带负载直接测试。
- 先完成单个模块测试，再进行整车联调。
- PID 参数从小到大逐步调整，并记录每次实验结果。
- 使用串口绘制目标速度和实际速度曲线，便于分析超调与振荡。
- 比赛前准备多组参数，以适应不同场地和电池电量。
